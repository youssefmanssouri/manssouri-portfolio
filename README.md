## 🏗️ Portfolio Architecture & Features

- **Editorial Design System**: Bespoke aesthetic using warm cream alabaster (`#F3EFEA`), deep burgundy (`#3A171C`), charcoal (`#242222`), and terracotta accents (`#A65F4B`).
- **Bilingual Internationalization (EN / FR)**: Full localization parity with persistent client language state.
- **Case Study Navigation**: Sticky section table of contents with scroll spy, build scope checklists, and verifiable product evidence.
- **SEO & Structured Data**: Dynamic OpenGraph tags, JSON-LD Schema (`Person`, `WebSite`, `WebApplication`, `BreadcrumbList`), and semantic hierarchy.
- **Lead Capture & Direct Routing**: Categorized inquiry form with validation, honeypot spam protection, and WhatsApp/Email routing.

## ⚙️ Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/youssefmanssouri/manssouri-portfolio.git
cd manssouri-portfolio

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env

# 4. Generate Prisma client & run migrations
npx prisma generate
npx prisma db push

# 5. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
